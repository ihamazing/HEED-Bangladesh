Validation Rules
Gender — Male or Female only
Diabetes / Cough / Fever / Weight Loss / Swelling — Cannot be blank
Cough Duration — Required if Cough=Yes, max 60 days, cannot be 0
Fever Duration — Required if Fever=Yes, max 60 days, cannot be 0
Night Sweats — Age <15: blank or "No" only ("Yes" flagged) · Age ≥15: cannot be blank (must be Yes/No)
Playfulness — Age <15: "Yes" or "No" · Age ≥15: "No" or blank only ("Yes" flagged)
Child Diabetes — Age <15 with Diabetes=Yes is flagged
Advised/Done mismatch — Test Done=Yes but Advised=No
GXP Sputum + Cough=No — GXP Sputum done without reported cough
TB Entry vs. Diagnosed Date (TB Cases tab) — Entry date must be on/after the Diagnosed date
